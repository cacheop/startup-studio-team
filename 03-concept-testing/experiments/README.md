# Experiment records

Copy [TEMPLATE.md](TEMPLATE.md) to a stable experiment ID, such as `EXP-001.md`. Change `record_type` to `experiment`, set `experiment_id` to the filename stem, and record an owner. Keep the ID if the experiment title changes.

Use `planned`, `running`, `complete`, or `cancelled` for status. Record the hypothesis, method, success criterion, and planned dates before running the experiment. Record actual dates, results, limitations, and the decision afterward. Explain changes to the method or success criterion.

A planned experiment supplies a plan, not result evidence. Link original results from the [evidence directory](../evidence/README.md) or their existing location.
