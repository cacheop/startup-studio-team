# Venture decisions

Copy [TEMPLATE.md](TEMPLATE.md) to a dated filename in `YYYY-MM-DD.md` format. Add a short suffix when several decisions share a date. Change `record_type` to `decision` and set the author and decision date.

Use `pursue`, `change_direction`, `pause`, or `stop` for the decision. Describe the previous position, evidence considered, alternatives, reasons, and consequences. Link the resulting current conclusion from the viability summary.

Preserve previous decisions and document later changes in new records.
