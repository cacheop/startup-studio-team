# Interview records

Copy [TEMPLATE.md](TEMPLATE.md) to a dated, descriptive filename. Change `record_type` to `interview` and complete the author and observation date. Use a stable participant ID when a name is unnecessary.

Record the participant's relevant context, the method, observations, and attributed quotations. Separate the participant's statements from the team's interpretation. State the limits of the interview and link the original source when available.
