# Startup team

This repository is a company-team template. It contains no company information or completed research yet.

## Start here

1. Create your team's repository with GitHub's **Use this template** button.
2. Replace this title with the company name and complete the overview below. Set the metadata when you know its values.
3. Start with the topic that matches your current work. Update its summary and link the supporting evidence.
4. Copy the [weekly update form](updates/TEMPLATE.md) for each reporting week and record what changed.

Keep unknown information explicit. The [record format](docs/FORMAT.md) defines dates, metadata, evidence records, and CSV columns. Git stores earlier versions when you commit changes.
