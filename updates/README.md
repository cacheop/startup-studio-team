# Weekly updates

Create one dated record for each reporting week. Copy [TEMPLATE.md](TEMPLATE.md) to a file named with the reporting date in `YYYY-MM-DD.md` format. Change `record_type` to `update` and set the author, recorded date, and period covered.

Describe the previous commitment and its outcome, new evidence, changed conclusions, blockers, and the next commitment. Link to the detailed work at its existing location. Record a week without new evidence explicitly.

After adding an update, link it from the company overview. Keep the template available for the next week.
