# Product assets

Keep wireframes, designs, screenshots, and demonstrations. Identify whether each artifact is a mockup, working prototype, or released product.

## Add an asset

Give each file a descriptive name and link it from the relevant analysis or summary. Explain its purpose and date in Markdown. For external files, record the owner, link, and access date. Keep one current source for each artifact.
