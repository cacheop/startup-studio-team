## Definition changes

Preserve the meaning of previous observations when a calculation changes. Add a new definition version and explain which periods use it.

## Observation rules

Record the measurement period and source for each observation. Use zero only for an observed zero; an empty value means unknown. Follow the [CSV format](../docs/FORMAT.md#csv-tables).
