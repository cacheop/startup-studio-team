# Traction evidence

Keep analytics exports, payment summaries, pilot outcomes, and customer commitments. Include measurement periods and sources.

## Add a record

Create a Markdown note with a descriptive dated filename. Identify the author, observation date, source, and finding. Include the method, sample, and limitations when relevant. Link original files and identify the claims they support or challenge.

Use relative links within this repository. Add the record to the topic summary once it exists. Follow the [record format](../../docs/FORMAT.md).
